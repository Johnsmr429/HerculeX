# records

Measured results that the calibration studies write and later steps read, as JSON beside the code.

```text
ink/       readers scored on held-out labels, model agreement, fibre polarity, the published windows richest in text
surface/   ink kept by a surface against the published one, piece truth, wrap studies, fibre faces
```

A number goes here only with the control it was measured against. Large study outputs go to the library's
`calibration/STUDY/`.
